# Sroka Android (`apps/android`)

Native Android client (Kotlin, Compose, Room, WorkManager). Own Gradle root — not an npm workspace.
**Binding rulings: `docs/DECISIONS.md`** (A1–A12; overrides template docs). Server contract: repo `docs/api.md`. Progress: `docs/LEDGER.md`.
Built from the ai-android-template (adopted as `app.sroka`); template guides under `docs/` describe the inherited infrastructure (testing layers, screenshots, releasing).

## Commands (run in `apps/android`)
- JDK 21 required: `export JAVA_HOME=$(/usr/libexec/java_home -v 21)`
- One module: `./gradlew :core:data:testDebugUnitTest --console=plain 2>&1 | tail -30`
- Flavors (dimension `distribution`, repo-root D15): `play` (Firebase Analytics + Crashlytics, the only published flavor) and `foss` (no Google/Firebase dependency). Only `:app` has flavors, so app tasks carry the flavor name: `:app:testPlayDebugUnitTest`, `:app:lintPlayDebug`, `:app:assemblePlayDebug`, `:app:assemblePlayRelease`, `:app:bundlePlayRelease`, `:app:installPlayDebug` (and `Foss` equivalents); library modules keep `testDebugUnitTest`/`lintDebug`.
- Gate play: `./gradlew testDebugUnitTest :app:testPlayDebugUnitTest lintDebug :app:lintPlayDebug :app:assemblePlayDebug :app:assemblePlayRelease --console=plain 2>&1 | tail -30` (`assemblePlayRelease`/`bundlePlayRelease` need `app/google-services.json`; without it they fail with a clear message, so use `:app:assembleFossRelease` instead locally).
- Gate foss: `./gradlew :app:testFossDebugUnitTest :app:lintFossDebug :app:assembleFossDebug :app:assembleFossRelease --console=plain 2>&1 | tail -30`
- Firebase config: gitignored `app/google-services.json` (clients `app.sroka` + `app.sroka.debug`); template `app/google-services.example.json`. Without it the google-services/Crashlytics plugins are not applied and telemetry is a no-op. Debug builds never send.
- Screenshot tests (Compose Preview Screenshot Testing; `src/screenshotTest` of core:designsystem, feature:{auth,library,settings}:impl, app; `@FoldablePreviews` = Folded/Unfolded/Unfolded landscape): update references `./gradlew :<module>:updateDebugScreenshotTest`, check `./gradlew :<module>:validateDebugScreenshotTest` (e.g. `:feature:library:impl`); `:app` is flavored: `:app:updatePlayDebugScreenshotTest` / `:app:validatePlayDebugScreenshotTest` (references in `app/src/screenshotTestPlayDebug`). Tests use stateless `…Content` composables + fixed fixtures; WebView/NavDisplay don't render.
- Install debug on a running emulator: `./gradlew :app:installPlayDebug`; local backend: repo root `npm run dev -w @sroka/api`, then `adb reverse tcp:8787 tcp:8787` (debug default server `http://localhost:8787`; dev OTP is printed in the wrangler log as `[sroka] OTP for …`).

## Telemetry (D15)
- `Telemetry` + `TelemetryEvent` (enum-backed params only) in `core:domain`; `FakeTelemetry` in `core:testing`. `app/src/play` binds the Firebase impl (no-op when FirebaseApp is not initialised or in debug builds), `app/src/foss` binds `Telemetry.None`. Consent (`analytics: Boolean?`, `crashReports` default true) lives in `core:datastore` `ConsentStore`; `ConsentApplier` (core:data) applies it at start and on change. Events are logged by the decorated repositories in `core/data/.../telemetry/` plus a few view models. Never pass URLs, titles, search text, tag names or ids.

## Layout
`app` (activities, nav, workers wiring) · `feature/{auth,library,reader,settings}/{api,impl}` · `core/{model,common,designsystem,ui,database,datastore,network,data,testing}` — see DECISIONS A2.

## Contracts
- Interfaces: `core/domain/src/main/kotlin/app/sroka/core/domain/*.kt`; models: `core/model/.../core/model/*.kt`; fakes: `core/testing/.../core/testing/fake/Fake*.kt`, builder `testItem()`.
- Nav keys: `feature/*/api/.../*Keys.kt`; entries `fun EntryProviderScope<NavKey>.<feature>Entries(callbacks…)` in `feature/*/impl/.../navigation/`; wired in `app/.../navigation/SrokaNavHost.kt`.
- `:app` depends on core:data (which binds every domain interface) and provides `AppBuildInfo` (`app/.../di/AppModule.kt`). `SrokaApplication` starts `SyncInitializer`; `ShareActivity` hosts the library's `SaveSheetHost`.
- Compose UI tests under Robolectric pin `@Config(sdk = [35])` (Robolectric 4.17 input injection fails on SDK 37).

## Conventions
- Local-first: UI reads Room only; user actions write Room + `pending_ops` in one transaction (A7). Network only in SyncEngine/ContentStore.
- Room: never destructive migrations; bump version + Migration + test; schemas exported to `core/database/schemas`.
- No raw exception text in UI; typed errors → string resources. Preserve coroutine cancellation.
- Strings in resources; icon buttons have content descriptions.
- Icons: only `SrokaIcons` (core:designsystem, generated by `scripts/gen-icons.py` from Material Symbols Rounded). Never add material-icons-* dependencies (they add ~11k classes to debug dex and a 13 s cold start).
