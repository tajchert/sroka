# Sroka iOS

Native SwiftUI client (iOS/iPadOS 27.0+, Xcode 27.2, Swift 6 strict concurrency) with feature parity to Android.
All code lives in one local Swift package, `Modules/`; the Xcode project is a thin shell. Conventions and their
reasons: `ARCHITECTURE.md`. Module ownership, product rulings and agent rules: `docs/BRIEF.md`.

## Layout

```
Sroka.xcodeproj   thin shell: targets Sroka, SrokaShare, SrokaUITests; schemes "Sroka Dev", "Sroka Prod"
App/              app target: composition root (AppComposition), root navigation (RootView), assets
Share/            share extension (ShareViewController hosts the ShareFeature sheet)
UITests/          XCUITest target (end-to-end flows only)
Config/           xcconfig: Debug/Release x Dev/Prod; optional gitignored Local.xcconfig (DEVELOPMENT_TEAM)
Modules/          ONE local Swift package
  Sources/        SrokaCore (models, domain protocols, Logic/), SrokaTesting (fakes, fixtures),
                  SrokaDesign (colours, type, glass, Components/), SrokaNetwork, SrokaDatabase,
                  SrokaSync, SrokaContent, SrokaSession, <Name>Feature x7
  Tests/          one <Module>Tests target each, plus SnapshotTests
scripts/verify.sh the one script for format, tests and builds
docs/             BRIEF.md (shared contract), LEDGER.md (orchestrator), plan/
```

## Commands

Run everything through `scripts/verify.sh` (any directory, any worktree):

| Command | Does |
|---|---|
| `scripts/verify.sh format` | swift-format lint, strict; non-zero on any finding |
| `scripts/verify.sh format-fix` | rewrite Swift sources in place |
| `scripts/verify.sh unit [Target...]` | package unit + snapshot tests; e.g. `unit LibraryFeatureTests` |
| `scripts/verify.sh build [Dev\|Prod]` | build the app for the simulator (default Dev) |
| `scripts/verify.sh ui` | UI tests (slow; not part of `all`) |
| `scripts/journey.sh` | live-backend journeys (`UITests/SrokaJourneyTests`) against a running `wrangler dev`; reinstalls the app on `SIM_NAME` (`sroka-*` only); see its header |
| `scripts/verify.sh all` | format, unit, build Dev, build Prod |

- Simulator: `SIM_NAME` (default `iPhone 18 Pro`) and `SIM_OS` (default `27.2`) select the destination.
- Run `scripts/verify.sh format` before every commit. New source directories go in `FORMAT_PATHS` in `scripts/verify.sh`.
- `xcodebuild -quiet` prints nothing on success; check the exit code.
- App icon: generated by `scripts/make-icons.mjs` at the repo root (`App/Assets.xcassets/AppIcon.appiconset/AppIcon.png`).

## Conventions

- Dependency rule (enforced by `Modules/Package.swift`): features import only `SrokaCore`, `SrokaDesign` and `SrokaTesting`; never each other or data/engine modules. Only the app and share extension import engine/data modules.
- Domain protocols live in `SrokaCore/Domain`: `AsyncStream` for observations (new stream per call, current value first), `async` for one-shot work, result enums for expected failures. Each has a `@Dependency` key; `testValue` reports an issue when called.
- Previews and tests use the fakes: `withDependencies { $0.useFakes(fakes) }` with `let fakes = Fakes()` (or `Fakes.empty`), sample data in `Fixtures`.
- View models are `@Observable @MainActor final class` and never import SwiftUI (they import `Observation`).
- Inject services with `@ObservationIgnored @Dependency(...)`. Never call `Date()`, `UUID()` or `Task.sleep` in a view model; use `\.date`, `\.uuid`, `\.continuousClock`.
- View model method names are user intentions (`archiveSwiped`, `itemTapped`). Presentation state is a stored `Bool` or optional on the view model.
- Each section of a screen is its own `View` type. Size class decides layout, never device or orientation.
- Colours: `SrokaColor.*` (paper tones for content, system glass for chrome); brand blue only for the accent and Save (`saveButtonStyle()`). Fonts: SF text styles; `Font.brandHeading(_:)` (Outfit) for brand headings only.
- Words come from `Vocabulary` (copied from `packages/shared/src/vocab.ts`). Put `bundle: #bundle` on localized literals in package code; text from view models is `LocalizedStringResource`.
- Telemetry (D15): enum-only parameters, never URLs, titles, tags, emails or search text. Logs: no secrets, emails or article content.
- Item ids become file names and URLs: validate with `isValidItemId` (`^[A-Za-z0-9_-]{1,64}$`).
- `SortOrder` is `LibrarySortOrder` here (Foundation already has `SortOrder`).

## Tests

- Swift Testing with sentence-case backtick names: ``@Test func `Search is debounced`()``; assert with `#expect` / `#require`.
- `SnapshotTests` keep plain identifiers and are valid only on iPhone 18 Pro / iOS 27.2. Never re-record unless your task says so.
- UI tests are XCTest (`test` prefix) and use the `-UITests` launch argument, the app's only test hook.

## Working in parallel

- Each agent works in its own git worktree and edits only the modules it owns (`docs/BRIEF.md`) plus its own lines in `Modules/Package.swift`.
- Use your own simulator: `xcrun simctl create sroka-<stream> "iPhone 18 Pro"`, run with `SIM_NAME=sroka-<stream>`, and `xcrun simctl delete sroka-<stream>` when done. Never shut down, erase or delete simulators you did not create.
- Run only your module's test targets (`unit <Target>`) plus `build Dev` before handoff; leave `all` and UI tests to the integrator.
- The UI test runner can stall after printing results; kill it once the results are in.
